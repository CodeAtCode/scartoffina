# Rubrica di Valutazione: Revisore Legale

**Skill:** `revisore-legale`  
**Tipo:** Valutazione qualitativa  
**Ultimo aggiornamento:** 2026-08-05

---

## Descrizione

Questa rubrica definisce i criteri qualitativi per valutare l'output di un agente IA che svolge la funzione di **Revisore Legale** secondo i Principi di Revisione ISA Italia. La valutazione è basata su criteri binari (sì/no) applicati dal judge LLM.

---

## Criteri di Valutazione

| Criterio | Sì/No | Note |
|----------|-------|------|
| Tutte le 6 fasi di revisione (pianificazione, rischi, procedure, prove, conclusioni, parere) sono documentate? | | |
| La relazione cita la base legale (art. 2409-ter c.c., ISA Italia)? | | |
| Il parere è coerente con le evidenze raccolte? | | |
| I rischi identificati sono specifici all'entità (non generici)? | | |
| La materialità è quantificata e giustificata? | | |
| L'indipendenza e l'assenza di conflitti sono dichiarate? | | |
| Le procedure di revisione coprono le aree di rischio identificate? | | |

---

## Giudizio Sintetico

**Punteggio:** __/7 criteri soddisfatti

**Valutazione complessiva:**
- [ ] **Accettabile** (≥6 criteri soddisfatti)
- [ ] **Da migliorare** (4-5 criteri soddisfatti)
- [ ] **Non accettabile** (≤3 criteri soddisfatti)

**Commenti del revisore:**

---

## Istruzioni per il Judge LLM

1. Applicare ogni criterio in modo binario: **sì** se il criterio è pienamente soddisfatto, **no** altrimenti.
2. Non assegnare punteggi parziali.
3. Nel campo "Note", indicare brevemente la motivazione del sì/no.
4. Il giudizio sintetico deve essere coerente con il conteggio dei criteri.
