# Tabelle millesimali — Guida alla costruzione e verifica

## Definizione

Le tabelle millesimali sono lo strumento per ripartire le spese condominiali in base al valore di ogni unità immobiliare. Il totale è sempre 1000 millesimi.

## Criteri di costruzione

### Valore proporzionale (art. 68 R.D. 633/1972 attuativo c.c.)

Le tabelle si basano sul **valore commerciale** di ogni unità, non sulla superficie. Tuttavia, in assenza di dati diversi, si usa la superficie corretta per:

- Piano (piani alti valgono di più)
- Esposizione (panoramico, luminoso)
- Pertinenze (box, cantinati, giardini)
- Stato manutentivo

### Superficie 

Se basate su superficie, le tabelle considerano:
- Superficie netta calpestabile
- Millesimi separati per box, cantinati, solai
- Millesimi di riscaldamento (volume, non superficie)

### Coefficienti correttivi

```
Valore_unità = Superficie × Coefficiente_piano × Coefficiente_esposizione
Millesimi_unità = (Valore_unità / Valore_totale) × 1000
```

Coefficienti tipici:
- Piano terra: 0,90
- Piano rialzato: 1,00
- Piano nobile: 1,10
- Ultimo piano: 0,95

## Tipi di tabelle

### 1. Tabella millesimale generale

Usata per spese comuni (pulizia, illuminazione, portierato). Somma = 1000.

### 2. Tabella millesimale di scala

Per spese relative a una singola scala (ascensore, pulizia scale). Somma della singola scala = 1000.

### 3. Tabella millesimale di riscaldamento

Per spese di riscaldamento centralizzato. Basata sul **volume** dell'unità, non sulla superficie.

```
Millesimi_riscaldamento = (Volume_unità / Volume_totale) × 1000
```

## Verifica delle tabelle

Prima di utilizzare una tabella per il riparto:

1. **Somma = 1000**: verificare che i millesimi sommino esattamente a 1000
2. **Unicità**: ogni unità appare una sola volta
3. **Coerenza con NCEU**: confrontare con la planimetria catastale
4. **Aggiornamento**: verificare se ci sono state modifiche (fusioni, divisioni)
5. **Approvazione**: verificare che la tabella sia stata approvata dall'assemblea

## Modifica delle tabelle

Le tabelle possono essere modificate:
- **Unanimità**: per modifiche sostanziali
- **Maggioranza qualificata** (4/5): per rettifiche ed errori materiali (art. 69 Disposizioni attuative)
- **Perizia**: in caso di contestazione, nomina perito

## Caso pratico

Condominio con 10 unità, superficie totale 1000 mq:

| Unità | Superficie | Coeff. | Valore | Millesimi |
|-------|-----------|--------|--------|-----------|
| A     | 100 mq    | 1,10   | 110    | 110       |
| B     | 80 mq     | 1,00   | 80     | 80        |
| C     | 120 mq    | 0,95   | 114    | 114       |
| ...   | ...       | ...    | ...    | ...       |
| Totale| 1000 mq   | -      | 1000   | 1000      |
