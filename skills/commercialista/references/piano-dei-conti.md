# Piano dei Conti Italiano — Struttura e Classificazione

**Base normativa**: Codice Civile (artt. 2423-2435), OIC 12 (Principi di redazione del bilancio), CEC-CNR 12/2016.

## Struttura Classica del Piano dei Conti

Il piano dei conti italiano segue la classificazione a 4 cifre (classe + gruppo + conto + sottoconto):

### Classi del Piano dei Conti

| Classe | Descrizione | Esemplificazione |
|--------|-------------|------------------|
| **1** | Crediti verso soci per versamenti ancora dovuti | 1.01 — Soci c/versamenti |
| **2** | Immobilizzazioni | 2.01 — Immobilizzazioni immateriali, 2.02 — Immobilizzazioni materiali |
| **3** | Attivo circolante | 3.01 — Rimanenze, 3.02 — Crediti, 3.03 — Strumenti finanziari, 3.04 — Disponibilità liquide |
| **4** | Patrimonio netto | 4.01 — Capitale sociale, 4.02 — Riserve, 4.03 — Utile/Perdita d'esercizio |
| **5** | Passività | 5.01 — Debiti verso banche, 5.02 — Debiti verso fornitori, 5.03 — Debiti tributari |
| **6** | Costi della produzione | 6.01 — Costi per materie prime, 6.02 — Costi per servizi, 6.03 — Costi per il personale |
| **7** | Ricavi e variazioni in capitali | 7.01 — Ricavi da vendite, 7.02 — Variazione rimanenze, 7.03 — Proventi finanziari |

## Convenzioni di Registrazione

### Partita Doppia Standard

Ogni scrittura deve rispettare il principio della partita doppia:

```
CONTO DARE | IMPORTO DARE | CONTO AVERE | IMPORTO AVERE
```

**Regola fondamentale**: Somma Dare = Somma Avere

### Esempi di Scritture Tipiche

**Acquisto merci con IVA 22%**:
```
6.01.001 Acquisti merci          1.000,00
41.01 IVA a credito                220,00
  5.03.001 Debiti verso fornitori           1.220,00
```

**Vendita servizi con IVA 22%**:
```
3.02.001 Crediti verso clienti    2.440,00
  7.01.003 Ricavi servizi                   2.000,00
  5.04.004 Debiti IVA a debito               440,00
```

**Pagamento fattura fornitore**:
```
5.03.001 Debiti verso fornitori  1.220,00
  3.04.003 Depositi bancari                 1.220,00
```

**Incasso fattura cliente**:
```
3.04.003 Depositi bancari        2.440,00
  3.02.001 Crediti verso clienti            2.440,00
```

## Note Operative

1. **Numerazione**: I conti possono essere estesi con sottoconti (es. 6.01.001.001 per fornitore specifico)

2. **Denominazione**: Mantenere denominazioni coerenti con la classificazione OIC

3. **Attivazione nuovi conti**: Documentare ogni nuovo conto aggiunto al piano

4. **Archiviazione**: I conti dismessi vanno mantenuti ma marcati come "non attivo"

5. **Allineamento fiscale**: Verificare allineamento con codici tributo F24 per la dichiarazione
