# Principi Contabili OIC per la Revisione

Guida ai Principi OIC (Organismo Italiano di Contabilità) più rilevanti per la revisione legale, con focus su red flags e procedure di verifica.

## 1. Panoramica dei Principi OIC

L'OIC (Organismo Italiano di Contabilità) emana i principi contabili italiani. I principali per la revisione sono:

| Principio | Oggetto | Rilevanza revisione |
|-----------|---------|---------------------|
| OIC 12 | Rappresentazione del bilancio | Fondamentale |
| OIC 11 | Determinazione del reddito | Alta |
| OIC 1 | Struttura del bilancio | Media |
| OIC 15 | Strumenti finanziari | Alta |
| OIC 16 | Immobilizzazioni materiali | Alta |
| OIC 24 | Rimanenze | Alta |
| OIC 28 | Eventi successivi | Media |
| OIC 29 | Incertezze e stime | Alta |

## 2. OIC 12 - Rappresentazione del Bilancio

### 2.1 Struttura del Bilancio

**Stato Patrimoniale**:
```
ATTIVO
A. Crediti verso soci per versamenti ancora dovuti
B. Immobilizzazioni
   I. Immateriali
   II. Materiali
   III. Finanziarie
C. Attivo circolante
   I. Rimanenze
   II. Crediti
   III. Attività finanziarie
   IV. Disponibilità liquide
D. Ratei e risconti attivi

PASSIVO
A. Patrimonio netto
   I. Capitale sociale
   II. Riserve
   III. Utile/Perdita d'esercizio
B. Fondi per rischi e oneri
C. Debiti
   I. Verso banche
   II. Verso fornitori
   III. Verso società controllate
   IV. TFR
   V. Altri debiti
D. Ratei e risconti passivi
```

**Conto Economico**:
```
A. Valore della produzione
   1. Ricavi delle vendite
   2. Variazione rimanenze
   3. Lavori in corso
   4. Altri ricavi
B. Costi della produzione
   5. Materie prime
   6. Servizi
   7. Personale
   8. Ammortamenti
   9. Oneri diversi
A-B = Risultato operativo

C. Proventi e oneri finanziari
D. Rettifiche valore attività finanziarie
E. Imposte

A-B+C+D-E = Utile/Perdita d'esercizio
```

### 2.2 Red Flags OIC 12

| Segnale | Possibile problema | Procedura |
|---------|-------------------|-----------|
| Patrimonio netto negativo | Perdite accumulate | Verifica continuità aziendale |
| Debiti > 2 anni senza scadenza | Ristrutturazione in corso | Verifica accordi con creditori |
| Ratei/risconti anomali | Taglio esercizi errato | Test taglio esercizi |
| Fondi rischi elevati | Sottostima utili | Verifica adeguatezza fondi |
| Crediti in forte crescita | Rallentamento incassi | Analisi invecchiamento |

### 2.3 Procedure di Verifica OIC 12

```
1. VERIFICA SCHEMI
   - Conformità a art. 2424-2425 c.c.
   - Classificazione corretta
   - Numerazione sequenziale

2. VERIFICA COERENZA
   - SP ↔ CE (utile/Perdita)
   - SP ↔ Nota Integrativa
   - Confronto esercizio precedente

3. VERIFICA VALUTAZIONI
   - Principi applicati correttamente
   - Costanza criteri
   - Disclosure adeguate
```

## 3. OIC 11 - Determinazione del Reddito d'Esercizio

### 3.1 Principi Chiave

**Principio di competenza**:
- I ricavi e i costi sono imputati al periodo di riferimento
- Indipendentemente dai flussi di cassa

**Principio di prudenza**:
- I costi sono rilevati quando probabili
- I ricavi sono rilevati quando certi

**Principio di costanza**:
- Criteri di valutazione devono essere costanti
- Variazioni devono essere motivate e disclose

### 3.2 Red Flags OIC 11

| Segnale | Possibile problema | Procedura |
|---------|-------------------|-----------|
| Ricavi in crescita senza cassa | Fatture senza incassi | Riconciliazione ricavi/incassi |
| Costi capitalizzati | Sottostima costi | Verifica criteri capitalizzazione |
| Ammortamenti ridotti | Estensione vita utile | Verifica aliquote ammortamento |
| Fondo rischi diminuito | Manipolazione utili | Verifica movimenti fondo |
| Variazioni rimanenze anomale | Manipolazione margini | Conteggio fisico |

### 3.3 Procedure di Verifica OIC 11

```
1. VERIFICA RICAVI
   - Fatture emesse vs contratti
   - Riconoscimento al momento giusto
   - Cut-off corretto

2. VERIFICA COSTI
   - Costi competenza vs pagamenti
   - Capitalizzazione appropriata
   - Accantonamenti adeguati

3. VERIFICA MARGINI
   - Confronto con settore
   - Variazioni significative
   - Motivazioni economiche
```

## 4. OIC 1 - Struttura del Bilancio

### 4.1 Requisiti di Forma

**Stato Patrimoniale**:
- Schemi obbligatori art. 2424 c.c.
- Voce per voce, senza compensazioni
- Importi in euro, senza decimali

**Conto Economico**:
- Schemi obbligatori art. 2425 c.c.
- Classificazione per natura o destinazione
- Coerenza con esercizio precedente

**Nota Integrativa**:
- Spiegazione voci di bilancio
- Criteri di valutazione
- Informazioni supplementari

### 4.2 Red Flags OIC 1

| Segnale | Possibile problema | Procedura |
|---------|-------------------|-----------|
| Schema non conforme | Violazione formale | Verifica art. 2424-2425 |
| Compensazioni attive/passive | Violazione principio | Verifica separazione |
| Mancata nota integrativa | Violazione obbligo | Richiesta integrazione |
| Criteri non disclose | Mancata trasparenza | Richiesta disclosure |

## 5. OIC 15 - Strumenti Finanziari

### 5.1 Classificazione

**Strumenti finanziari passivi**:
- Debiti verso banche
- Obbligazioni emesse
- Derivati passivi

**Strumenti finanziari attivi**:
- Titoli in portafoglio
- Partecipazioni
- Derivati attivi

### 5.2 Valutazione

| Strumento | Valutazione iniziale | Valutazione successiva |
|-----------|---------------------|------------------------|
| Crediti commerciali | Valore nominale | Valore recuperabile |
| Titoli negoziazione | Fair value | Fair value (PL) |
| Titoli disponibile | Costo ammortizzato | Costo ammortizzato |
| Derivati | Fair value | Fair value (SP) |

### 5.3 Red Flags OIC 15

| Segnale | Possibile problema | Procedura |
|---------|-------------------|-----------|
| Derivati non hedge | Speculazione non disclose | Verifica finalità |
| Fair value non verificabile | Valutazione arbitraria | Richiesta perito |
| Strumenti complessi | Rischio non compreso | Verifica comprensione |
| Leverage elevato | Rischio finanziario | Analisi flussi cassa |

### 5.4 Procedure di Verifica OIC 15

```
1. IDENTIFICAZIONE
   - Lista completa strumenti
   - Classificazione corretta
   - Finalità utilizzo

2. VALUTAZIONE
   - Fair value verificato
   - Metodi appropriati
   - Sensitivity analysis

3. DISCLOSURE
   - Rischio di mercato
   - Rischio di credito
   - Rischio di liquidità
```

## 6. OIC 16 - Immobilizzazioni Materiali

### 6.1 Criteri di Rilevazione

**Costo di acquisto**:
```
Costo = Prezzo di acquisto + Dazi + Trasporto + Installazione
        - Sconti - Abbuoni
```

**Costo di produzione**:
```
Costo = Materie prime + Manodopera + Costi diretti
        + Ammortamenti diretti
```

**Soglie di capitalizzazione**:
- Beni > 516,45€ con vita > 1 anno → immobilizzazione
- Beni < 516,45€ → costo immediato

### 6.2 Ammortamenti

**Aliquote tipiche**:
| Tipo bene | Aliquota |
|-----------|----------|
| Fabbricati civili | 2-2,5% |
| Fabbricati industriali | 4-5% |
| Impianti e macchinari | 10-20% |
| Attrezzature | 15-25% |
| Mobili e arredi | 10-20% |
| Mezzi di trasporto | 20-25% |
| Software | 20-33% |

**Metodi**:
- Lineare: quota costante
- Progressivo: quota crescente
- Degressivo: quota decrescente

### 6.3 Red Flags OIC 16

| Segnale | Possibile problema | Procedura |
|---------|-------------------|-----------|
| Vita utile estesa | Sottostima ammortamento | Confronto settore |
| Costi capitalizzati | Capitalizzazione errata | Verifica natura costi |
| Svalutazioni assenti | Sopravvaluta beni | Test impairment |
| Beni non assicurati | Rischio non coperto | Verifica polizze |
| Beni in disuso | Impairment necessario | Verifica utilizzo |

### 6.4 Procedure di Verifica OIC 16

```
1. ESISTENZA
   - Ispezione fisica beni
   - Verifica titoli di proprietà
   - Conferma locazioni

2. VALUTAZIONE
   - Costo storico verificato
   - Ammortamento corretto
   - Svalutazione adeguata

3. PROPRIETÀ
   - Visure catastali
   - Contratti acquisto
   - Assicurazioni
```

## 7. OIC 24 - Rimanenze

### 7.1 Criteri di Valutazione

**Metodi di valutazione**:
```
FIFO (First In, First Out)
- Primi entrati, primi usciti
- Rimanenze valutate al costo più recente

LIFO (Last In, First Out)
- Ultimi entrati, primi usciti
- Non più consentito OIC 2023+

Peso medio ponderato
- Costo totale / Quantità totale
- Valutazione media
```

**Principio di prudenza**:
```
Valore = Min(Costo, Valore di realizzo)

Se valore di realizzo < costo → svalutazione
Se valore di realizzo > costo → mantenimento costo
```

### 7.2 Red Flags OIC 24

| Segnale | Possibile problema | Procedura |
|---------|-------------------|-----------|
| Rimanenze in crescita | Merce invenduta | Analisi rotazione |
| Rotazione ridotta | Obsolescenza | Verifica età merce |
| Svalutazioni basse | Sopravvaluta rimanenze | Confronto settore |
| Costo > realizzo | Violazione prudenza | Ricalcolo valore |
| Rimanenze negative | Errori registrazione | Verifica movimenti |

### 7.3 Procedure di Verifica OIC 24

```
1. ESISTENZA
   - Osservazione inventario fisico
   - Conteggio campionario
   - Riconciliazione libro/fisico

2. VALUTAZIONE
   - Verifica costo di acquisto
   - Verifica valore di realizzo
   - Ricalcolo svalutazioni

3. TAGLIO ESERCIZI
   - Movimenti 30/12 e 01/01
   - Merci in transito
   - Fatture da ricevere
```

## 8. OIC 28 - Eventi Successivi

### 8.1 Tipologie

**Eventi Tipo 1** (rettifiche):
- Forniscono evidenza di condizioni esistenti al 31/12
- Esempi:
  - Fallimento cliente (credito già deteriorato)
  - Sentenza definitiva (passività già esistente)
  - Vendita a prezzo inferiore (svalutazione già necessaria)

**Eventi Tipo 2** (disclosure):
- Indicano condizioni sorte dopo il 31/12
- Esempi:
  - Incendio magazzino
  - Acquisto/sale di società
  - Cambiamento normativo

### 8.2 Red Flags OIC 28

| Segnale | Possibile problema | Procedura |
|---------|-------------------|-----------|
| Eventi significativi non disclose | Omissione disclosure | Verifica eventi |
| Rettifiche tardive | Manipolazione bilancio | Verifica tempistica |
| Contenzioso in corso | Passività non accantonata | Verifica avvocati |

### 8.3 Procedure di Verifica OIC 28

```
1. IDENTIFICAZIONE
   - Periodo: 31/12 → data relazione
   - Fonti: board, avvocati, banche
   - Eventi significativi

2. VALUTAZIONE
   - Tipo 1: rettifica bilancio
   - Tipo 2: disclosure nota integrativa
   - Incertezze: paragrafo enfasi

3. DOCUMENTAZIONE
   - Verbali board
   - Pareri legali
   - Comunicazioni banche
```

## 9. OIC 29 - Incertezze e Stime

### 9.1 Tipologie di Stime

| Stima | Base di calcolo | Rischio |
|-------|-----------------|---------|
| Fondo rischi | Probabilità × Importo | Sottostima |
| TFR | Maturazione annuale | Basso |
| Imposte | Aliquota × Imponibile | Interpretazione |
| Ammortamenti | Vita utile | Sopravvaluta beni |
| Svalutazioni | Valore recuperabile | Sopravvaluta |

### 9.2 Red Flags OIC 29

| Segnale | Possibile problema | Procedura |
|---------|-------------------|-----------|
| Stime cambiate frequentemente | Manipolazione utili | Verifica coerenza |
| Fondo rischi ridotto | Sottostima passività | Verifica eventi |
| Svalutazioni assenti | Sopravvaluta attività | Test impairment |
| Stime senza documentazione | Mancata tracciabilità | Richiesta base |

### 9.3 Procedure di Verifica OIC 29

```
1. VERIFICA BASE
   - Dati di partenza corretti
   - Assunzioni ragionevoli
   - Coerenza con settore

2. VERIFICA CALCOLO
   - Formula corretta
   - Calcolo matematico
   - Sensitivity analysis

3. VERIFICA DISCLOSURE
   - Incertezze disclose
   - Sensibilità disclose
   - Assumptions disclose
```

## 10. Checklist di Revisione per Principio

### 10.1 OIC 12 - Bilancio

- [ ] Schemi conformi art. 2424-2425
- [ ] Voce per voce, no compensazioni
- [ ] Nota integrativa completa
- [ ] Confronto esercizio precedente

### 10.2 OIC 16 - Immobilizzazioni

- [ ] Costo storico verificato
- [ ] Ammortamento appropriato
- [ ] Svalutazione se necessario
- [ ] Ispezione fisica beni

### 10.3 OIC 24 - Rimanenze

- [ ] Conteggio fisico eseguito
- [ ] Valutazione costo/realizzo
- [ ] Svalutazione obsolescenza
- [ ] Taglio esercizi verificato

### 10.4 OIC 28 - Eventi Successivi

- [ ] Eventi fino a data relazione
- [ ] Tipo 1: rettifiche applicate
- [ ] Tipo 2: disclosure complete
- [ ] Continuità aziendale valutata

### 10.5 OIC 29 - Stime

- [ ] Assunzioni ragionevoli
- [ ] Calcoli verificati
- [ ] Disclosure complete
- [ ] Coerenza esercizio precedente
