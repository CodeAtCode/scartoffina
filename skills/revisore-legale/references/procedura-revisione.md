# Procedura di Revisione Legale - Guida ISA Italia

Questa guida descrive in dettaglio le 7 fasi della procedura di revisione legale secondo i Principi di Revisione ISA Italia.

## 1. Panoramica del Processo di Revisione

```
Fase 1 → Fase 2 → Fase 3 → Fase 4 → Fase 5 → Fase 6 → Fase 7
Accettazione  →  Valutazione  →  Procedure  →  Prove  →  Conclusioni  →  Parere  →  Relazione
```

**Durata tipica**: 6-12 settimane per PMI
**Team minimo**: 1 revisore + 1 collaboratore

## 2. Fase 1: Accettazione e Pianificazione

### 2.1 Accettazione dell'Incarico (ISA Italia 210)

**Checklist di accettazione**:

| Item | Verifica | Documento |
|------|----------|-----------|
| Indipendenza | Nessun conflitto di interesse | Dichiarazione indipendenza |
| Competenza | Team qualificato per il settore | CV team |
| Risorse | Disponibilità tempo/personale | Piano risorse |
| Rischi | Rischi etici/professionali valutati | Valutazione rischi |
| Mandato | Lettera di incarico firmata | Lettera di incarico |

**Lettera di incarico** deve contenere:
- Obiettivi della revisione
- Responsabilità del revisore
- Responsabilità della direzione
- Scope della revisione
- Riferimento ai principi applicabili
- Formato della relazione

### 2.2 Comprensione dell'Entità (ISA Italia 315)

**Informazioni da raccogliere**:

```
1. DATI GENERALI
   - Forma giuridica, sede, attività
   - Struttura proprietaria
   - Organigramma
   - Consociate/partecipazioni

2. CONTESTO SETTORIALE
   - Andamento settore
   - Posizione competitiva
   - Regolamentazione specifica
   - Fattori economici rilevanti

3. SISTEMA DI CONTROLLO INTERNO
   - Ambiente di controllo
   - Processi di risk assessment
   - Attività di controllo
   - Informazioni e comunicazione
   - Monitoraggio

4. INFORMATIVA FINANZIARIA
   - Principi contabili adottati
   - Processi di chiusura
   - Sistemi informativi
   - Personale contabile
```

### 2.3 Determinazione Materialità (ISA Italia 320)

**Formula di base**:
```
Materialità bilancio = Base di riferimento × Percentuale

Base di riferimento tipica:
- Ricavi: 0,5-1%
- Totale attivo: 0,5-1%
- Utile prima delle imposte: 5-10%
```

**Esempio completo**:
```
Società: Alpha S.r.l.
Dati 2025:
- Ricavi: 10.000.000€
- Totale attivo: 8.000.000€
- Utile prima imposte: 800.000€

Calcolo materialità:
- Basato su ricavi: 10.000.000 × 0,75% = 75.000€
- Basato su attivo: 8.000.000 × 0,75% = 60.000€
- Basato su utile: 800.000 × 5% = 40.000€

Materialità scelta: 75.000€ (media ponderata)
Materialità esecuzione: 75.000 × 75% = 56.250€
Materialità minima: 56.250 × 50% = 28.125€
```

**Soglie operative**:
| Categoria | Importo | Azione |
|-----------|---------|--------|
| Pervasivo | > 75.000€ | Può modificare parere |
| Significativo | 56.250-75.000€ | Richiede attenzione |
| Da aggregare | 28.125-56.250€ | Sommare con altri errori |
| Trascurabile | < 28.125€ | Generalmente ignorare |

### 2.4 Piano di Revisione

**Elementi del piano**:
```
1. OBIETTIVI
   - Ottenere assicurazione ragionevole
   - Rilevare errori significativi
   - Esprimere parere motivato

2. AREE A RISCHIO
   - Rimanenze (valutazione complessa)
   - Crediti (rischio insolvenza)
   - Immobilizzazioni (valutazioni)
   - Ricavi (taglio esercizi)

3. RISORSE
   - Revisore: 40 ore
   - Collaboratore: 80 ore
   - Specialista: 10 ore (se necessario)

4. TEMPI
   - Pianificazione: 1 settimana
   - Esecuzione: 3 settimane
   - Conclusioni: 1 settimana
   - Totale: 5 settimane
```

## 3. Fase 2: Valutazione dei Rischi (ISA Italia 315)

### 3.1 Identificazione Rischi

**Matrice dei rischi**:

| Area | Rischio Intrinseco | Rischio Controllo | Rischio Rilevato |
|------|-------------------|-------------------|------------------|
| Cassa | Medio | Basso | Medio |
| Rimanenze | Alto | Medio | Alto |
| Crediti | Medio | Medio | Medio |
| Immobilizzazioni | Medio | Basso | Medio |
| Ricavi | Alto | Alto | Alto |
| Debiti | Basso | Basso | Basso |

**Fattori di rischio intrinseco**:
- Complessità delle operazioni
- Sensibilità delle stime
- Settore ad alto rischio
- Eventi straordinari

**Fattori di rischio di controllo**:
- Assenza di segregazione compiti
- Controlli non documentati
- Personale non qualificato
- Turnover elevato

### 3.2 Risposta ai Rischi (ISA Italia 330)

**Per rischi elevati**:
```
Procedura: Test di dettaglio esteso
Campioni: 100% o campione statistico grande
Conferme: Esterne obbligatorie
Ricalcolo: Indipendente su tutte le voci
```

**Per rischi medi**:
```
Procedura: Procedure analitiche + test di dettaglio
Campioni: Campione statistico moderato
Conferme: Esterne su campione
Ricalcolo: Su campione
```

**Per rischi bassi**:
```
Procedura: Procedure analitiche
Campioni: Campione ridotto o nessuno
Conferme: Non necessarie
Ricalcolo: Su campione minimo
```

## 4. Fase 3: Procedure di Revisione

### 4.1 Procedure Analitiche

**Tipologie**:
```
1. CONFRONTO TEMPORALE
   - Confronto con esercizi precedenti
   - Analisi trend
   - Variazioni > 10% da spiegare

2. CONFRONTO BUDGET
   - Confronto con budget/previsioni
   - Analisi scostamenti
   - Motivazioni variazioni

3. RAPPORTI FINANZIARI
   - Marginalità
   - Rotazione crediti
   - Rotazione magazzino
   - Indici di liquidità

4. CONFRONTO SETTORE
   - Benchmark con competitor
   - Indici di settore
   - Posizionamento competitivo
```

**Esempio analisi**:
```
Rapporto: Rotazione crediti
2024: 365 / (35.000.000 / 5.000.000) = 52 giorni
2025: 365 / (40.000.000 / 6.500.000) = 59 giorni

Variazione: +7 giorni (+13,5%)
Azione: Investigare causa rallentamento incassi
```

### 4.2 Test di Dettaglio

**Procedura standard per voce di bilancio**:

```
1. OTTENERE LISTA DETTAGLIATA
   - Estrazione dal sistema contabile
   - Riconciliazione con bilancio

2. VERIFICARE DOCUMENTAZIONE
   - Campionamento (statistico o giudiziale)
   - Richiesta documenti fonte
   - Verifica autenticità

3. CONFERME ESTERNE
   - Invio conferme a terze parti
   - Follow-up su non risposte
   - Procedure alternative

4. RICALCOLO
   - Verifica calcoli matematici
   - Verifica applicazioni principi
   - Verifica consistenza

5. TAGLIO ESERCIZI
   - Verifica transazioni fine periodo
   - Verifica registrazioni inizio periodo
   - Corretta imputazione temporale
```

### 4.3 Test dei Controlli

**Quando eseguire**:
- Quando si fa affidamento sui controlli
- Quando i controlli riducono il lavoro sostanzitivo

**Procedura**:
```
1. IDENTIFICARE CONTROLLO
   - Descrizione controllo
   - Frequenza esecuzione
   - Responsabile controllo

2. VERIFICARE PROGETTAZIONE
   - Il controllo è ben progettato?
   - Raggiunge l'obiettivo?
   - È documentato?

3. VERIFICARE ESECUZIONE
   - Il controllo è eseguito?
   - È eseguito coerentemente?
   - Chi esegue è qualificato?

4. DOCUMENTARE
   - Campione di test
   - Risultati test
   - Eccezioni rilevate
   - Conclusioni
```

## 5. Fase 4: Raccolta Prove (ISA Italia 500)

### 5.1 Tipologie di Prove

| Tipo | Descrizione | Affidabilità |
|------|-------------|--------------|
| Conferme esterne | Risposte da terze parti | Alta |
| Osservazione fisica | Conteggio inventario | Alta |
| Ricalcolo | Verifica matematica | Alta |
| Riesecuzione | Ripetizione procedura | Alta |
| Ispezione documenti | Verifica fatture/contratti | Media-Alta |
| Inchiesta | Domande alla direzione | Media |
| Procedure analitiche | Analisi rapporti | Media-Bassa |

### 5.2 Campionamento

**Metodi di campionamento**:

```
1. CAMPIONAMENTO STATISTICO
   - Selezione casuale
   - Dimensione calcolata statisticamente
   - Inferenza sulla popolazione

2. CAMPIONAMENTO GIUDIZIALE
   - Selezione basata su giudizio
   - Focus su elementi ad alto rischio
   - Non permette inferenza statistica

3. CAMPIONAMENTO PER UNITÀ
   - Test di tutte le unità sopra soglia
   - Esempio: tutte le fatture > 50.000€
```

**Dimensione campione tipica**:
| Rischio | Dimensione campione |
|---------|---------------------|
| Alto | 40-60 elementi |
| Medio | 25-40 elementi |
| Basso | 15-25 elementi |

### 5.3 Documentazione (ISA Italia 230)

**Elementi obbligatori**:
```
1. IDENTIFICAZIONE
   - Riferimento cartella
   - Titolo
   - Data

2. OBIETTIVO
   - Cosa si vuole dimostrare

3. PROCEDURA
   - Cosa è stato fatto
   - Come è stato fatto
   - Chi l'ha fatto

4. RISULTATI
   - Cosa è stato trovato
   - Eccezioni rilevate
   - Follow-up

5. CONCLUSIONI
   - Cosa significano i risultati
   - Impatto sul parere
```

**Regola dei 10 anni**:
- Cartella deve essere conservata per 10 anni
- Data di conservazione: data della relazione

## 6. Fase 5: Conclusioni (ISA Italia 700)

### 6.1 Valutazione Errori

**Classificazione errori**:
```
1. ISOLATI
   - Singolo evento
   - Non ripetitivo
   - Causa specifica

2. SISTEMATICI
   - Ripetuto nel tempo
   - Causa strutturale
   - Richiede correzione processo

3. FRODOLANTI
   - Intenzionale
   - Segnalare alla direzione
   - Valutare impatto su fiducia
```

**Valutazione impatto**:
```
Errore singolo:
- Confrontare con materialità minima
- Se > 50% materialità → significativo

Errori aggregati:
- Sommare tutti gli errori non rettificati
- Confrontare con materialità bilancio
- Se > 75% → possibile parere modificato
```

### 6.2 Continuità Aziendale (ISA Italia 570)

**Indicatori di rischio**:
```
FINANZIARI
- Perdite ricorrenti
- Capitale negativo
- Difficoltà accesso credito
- Violazione covenants

OPERATIVI
- Perdita cliente chiave
- Perdita fornitore chiave
- Sciopero/contenzioso lavoro
- Eventi avversi straordinari

ALTRI
- Cambiamento normativo avverso
- Contenzioso in corso
- Riforma settore
```

**Valutazione**:
```
1. ANALISI FLUSSI DI CASSA
   - Previsioni 12 mesi
   - Scenari base/pessimistico
   - Adeguamento risorse

2. VALUTAZIONE DEBITO
   - Scadenze debiti
   - Disponibilità crediti
   - Rinegoziazione possibile

3. VALUTAZIONE EVENTI
   - Eventi successivi al 31/12
   - Impatto sulla continuità

4. CONCLUSIONE
   - Continuità appropriata?
   - Incertezza significativa?
   - Disclosure adeguata?
```

### 6.3 Eventi Successivi (ISA Italia 560)

**Tipologie**:
```
EVENTI TIPO 1 (rettifiche)
- Forniscono evidenza di condizioni esistenti al 31/12
- Esempio: fallimento cliente (credito già deteriorato)
- Azione: Rettifica bilancio

EVENTI TIPO 2 (disclosure)
- Indicano condizioni sorte dopo il 31/12
- Esempio: incendio magazzino (evento nuovo)
- Azione: Disclosure in nota integrativa
```

**Periodo di responsabilità**:
```
Data bilancio: 31/12/2025
Data relazione: 15/03/2026
Deposito bilancio: 30/04/2026

Responsabilità revisore: Fino alla data della relazione (15/03)
Dopo la relazione: Solo se viene a conoscenza di fatti significativi
```

## 7. Fase 6: Parere (ISA Italia 700, 705)

### 7.1 Tipologie di Parere

**Parere senza modifiche**:
```
Condizioni:
- Bilancio rappresenta correttamente la situazione
- Nessuna discrepanza significativa
- Conformità a principi contabili
- Disclosure adeguate

Formula:
"Secondo la nostra opinione, il bilancio rappresenta in modo 
veritiero e corretto la situazione patrimoniale e finanziaria..."
```

**Parere con riserva**:
```
Condizioni:
- Discrepanza significativa ma non pervasiva
- Limitazione di portata non pervasiva

Formula:
"Ferma la riserva relativa a [descrizione], il bilancio 
rappresenta in modo veritiero e corretto..."
```

**Parere avversa**:
```
Condizioni:
- Discrepanza significativa E pervasiva
- Bilancio non rappresenta correttamente la situazione

Formula:
"A causa dell'effetto di [descrizione], il bilancio non 
rappresenta in modo veritiero e corretto..."
```

**Impossibilità di esprimere il parere**:
```
Condizioni:
- Limitazione di portata significativa E pervasiva
- Impossibilità ottenere evidenze sufficienti

Formula:
"A causa dell'impossibilità di [descrizione], non possiamo 
esprimere un parere sul bilancio..."
```

### 7.2 Decision Tree per Tipo di Parere

```
                    ┌─ Errori pervasivi? ── SÌ ── Parere AVVERSO
                    │
Errori rilevati? ───┤
                    │         ┌─ Errori significativi? ── SÌ ── Parere CON RISERVA
                    └─ NO ────┤
                              └─ NO ── Parere SENZA MODIFICHE
```

## 8. Fase 7: Relazione e Comunicazione

### 8.1 Struttura Relazione di Revisione

```
1. TITOLO
   "Relazione di revisione legale sul bilancio"

2. DESTINATARIO
   "All'Assemblea dei Soci di [Società]"

3. PARAGRAFO OPINIONE
   - Tipo di parere
   - Riferimento al bilancio

4. PARAGRAFO BASE PER L'OPINIONE
   - Conformità a ISA Italia
   - Indipendenza
   - Responsabilità etiche

5. PARAGRAFO RESPONSABILITÀ DIREZIONE
   - Preparazione bilancio
   - Controllo interno
   - Continuità aziendale

6. PARAGRAFO RESPONSABILITÀ REVISORE
   - Obiettivo revisione
   - Procedure eseguite
   - Evidenze ottenute
   - Giudizio professionale

7. PARAGRAFO EVENTI SIGNIFICATIVI (se applicabile)
   - Enfasi su aspetti specifici

8. DATA E FIRMA
   - Data non precedente approvazione bilancio
   - Firma revisore abilitato
```

### 8.2 Comunicazione ai Governanti (ISA Italia 260)

**Argomenti da comunicare**:
```
1. PIANIFICAZIONE
   - Approccio alla revisione
   - Aree di rischio identificate
   - Materialità applicata

2. RISULTATI
   - Procedure significative
   - Errori rilevati
   - Questioni di principio

3. CONTROLLI INTERNI
   - Carenze significative
   - Osservazioni gestionali
   - Raccomandazioni

4. ALTRE QUESTIONI
   - Difficoltà incontrate
   - Disaccordi con la direzione
   - Eventi successivi significativi
```

**Formato comunicazione**:
- Scritta per carenze significative
- Verbale o scritta per altre questioni
- Tempestiva (prima della relazione)
